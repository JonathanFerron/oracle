📊 Understanding the Metrics

Complexity (C) - Learning Curve

1.0 (Easiest) 6.0 (Most Complex)

Complexity measures how hard it is to learn and understand the rules. Factors: number of mechanics, rule interactions, edge cases to remember.

Depth (D) - Strategic Richness

1.0 (Shallowest) 7.5 (Deepest)

Depth measures strategic possibilities and skill ceiling once rules are learned. Factors: decision trees, meaningful choices, skill differentiation.

Each cell is split diagonally: upper-right triangle = Complexity, lower-left triangle = Depth
