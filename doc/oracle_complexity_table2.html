📍 Recommended Learning Paths

Beginner Path (Random): Start simple, add gradually
Monochrome Path: Easier combos, steady growth
Competitive Path: Custom deck mastery
Draft Expert Path: Ultimate complexity

🎯 Other Sensible Progression Routes

1. "Combo Master" Path:

Monochrome + Combos → Random + Combos → Solomon 7×7 + Combos → Custom + Combos
Focus: Learn combo system deeply before adding other mechanics

2. "Draft Specialist" Path:

Random + Combos → Solomon 7×7 + Combos → Draft 12×8 + Combos → Draft 1-2-3 + Combos + Abilities
Focus: Master drafting skills with minimal rules overhead

3. "Tactical Gamer" Path:

Monochrome + Combos + Abilities → Random + All → Custom + All (no Order Powers)
Focus: Champion abilities and momentum, skip Order Powers initially

4. "Fast Learner" Path:

Random + Combos → Monochrome + Combos + Abilities → Custom + All
Focus: Quick progression for experienced card game players

5. "Social/Casual" Path:

Monochrome + Combos → Solomon 7×7 + Combos + Abilities → Stop there
Focus: Fun, interactive play without excessive complexity

6. "Tournament Prep" Path:

Random + All → Custom + All → Draft 12×8 + All → Draft 1-2-3 + All
Focus: Full rules mastery, then draft format expertise

Design Insight: The top-left (Monochrome, No Combos) and bottom-right (Draft 1-2-3, All Additions) represent a complexity span of roughly 1 star to 7 stars. This 30-cell matrix provides flexible entry points for different player types while maintaining a clear progression toward mastery.
🎓 Teaching Recommendation: Most new players should start at either:
  • Monochrome + Combos (simpler combo rules, clearer deck theme)
  • Random + Combos (maximum variety, standard complexity)
Both paths lead naturally to more complex formats as skills develop.
