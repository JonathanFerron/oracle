Each cell is split into two triangles:

c

◤ Upper-left = Complexity (rules/mechanics burden)
◢ Lower-right = Depth (strategic richness / skill ceiling)

Color scale (heatmap, both triangles use the same scale):

1.0 (low) ~5.0 (mid) 9.0+ (high)

Blue → cool/simple, Yellow → moderate, Red → hot/complex or deep. Because d generally rises faster than c as you add Momentum and Order Powers, lower-right triangles trend redder than upper-left ones in the bottom rows — depth grows faster than raw complexity.

Design intent: Complexity (c) approximates how much new procedural/rules knowledge a player must hold in their head. Depth (d) approximates how much genuine strategic decision-space opens up. Notice cells can have d > c (a mechanic that's easy to learn but rich in strategy, e.g. Combo Bonuses) or c ≈ d (a mechanic that's about as hard to learn as it is deep, e.g. raw draft mechanics). Numbers are illustrative design estimates, not measured playtest data.
